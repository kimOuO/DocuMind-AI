# retrieval-parameters — 切塊大小 × Top-K × Vector／Hybrid，與相似度門檻（P4，AC-19）

一支工具（`app/backend/tests/integration/test_retrieval_parameters_real.py`，`make eval`）、一個切塊大小一個結果檔（`runs/chunk<size>.json`）、`analyse.py` 彙整成下表並寫 `analysis.json`。題庫與標準答案在 `../ground-truth/question-set.json`（19 題；證據是原始文件的逐字原文附頁碼，不用切塊編號，規格 02 §9.1）。

## 方法

- 三種切塊大小 256／400／600 tokens（重疊固定 20%），各重新入庫兩份論文（只做嵌入，不建摘要）。bge-m3 經 Ollama。
- 每題嵌入一次，在該題的文件範圍內檢索；無答案題只記 top-1 相似度。
- **Vector**：目前做法，餘弦相似度前 K。
- **Hybrid**：向量前 20 與 PostgreSQL 全文檢索前 20 以 Reciprocal Rank Fusion（k＝60）合併後取前 K。全文檢索用 `simple` 設定、`ts_rank_cd`、問題的拉丁字母與數字詞 OR 連接（第一次用整句 AND 語意，18 題有 16 題全文檢索零命中，已改；PostgreSQL 的 `simple` 不分中文詞，中文題只靠其中的英文與數字詞；排序不是嚴格 BM25）。在實驗工具內計算，不改正式程式。
- **Vector＋表格後文**：正式程式的路徑（D62）——前 K 命中表格時補入同章節緊接的討論段，最多兩塊。
- 涵蓋判定：切塊與證據同文件同頁，且證據文字在切塊內，或最長共同片段達證據字元的 50%（規格 §9.1）；表格列在入庫時被逐格改寫（ADR 0007），所以含四個以上數字的證據，切塊持有其 90% 以上的數字即算涵蓋。
- Recall@K＝一題證據被前 K 涵蓋的比例取平均；來源命中率＝至少涵蓋一筆的題目比例；證據 tokens＝前 K 的 token 總和平均。K＝3／5／8。
- 門檻掃描：0.30 到 0.60 每 0.05，計無答案題（3 題）正確拒答數與有答案題（15 題）誤拒答數。

## 讀法與結論

- **切塊 400 最好**：K＝5 時 Vector Recall 0.84、命中率 1.00；256 與 600 都較低（0.78、0.81），600 的證據 tokens 多三成。400×5 是目前預設，保留。
- **K**：400 下 K 由 5 到 8，Recall 0.84 → 0.88，證據 tokens 2,086 → 3,102（＋49%）；多出的 0.04 是 Q3 的定義段（正式程式的表格後文已補到，見 C 欄 0.88）。K 保留 5。
- **Hybrid 沒有贏**：400×5 時 Recall 0.81、命中率 0.93，低於 Vector 的 0.84／1.00；關鍵字型 9 題兩者同為 0.91。Hybrid 幫到 Q3（把定義段拉進前 5）、Q2（把 Table 1 拉進前 5），但在 D3、G4 把導論頁拉進來擠掉正確段。600×8 時 Hybrid 0.89 高於 Vector 0.84，但要 5,092 tokens，接近證據預算 5,500。依規格 §9.3 的採用條件（涵蓋率高於 Vector 且正確性不下降）未達成，**維持 Vector**。
- **相似度門檻**：目前 0.45 只能擋 3 題無答案題中的 1 到 2 題；0.50 三種切塊都是 3/3 正確拒答、0/15 誤拒答；0.55 開始誤拒 X1（跨文件題，top-1 0.54）。依 §9.5 應選 0.50，但餘裕只有 0.03 到 0.04，而且無答案題只有 3 題——這是「建議改為 0.50」的數據，不是強證據。
- **還是找不到的**：Q2 的 Table 1 GraphRAG 區塊不在 Vector 前 5（Hybrid 拉得到；navigate 模式的 Navigator 也是為此而設）；G2 的 Table 6（第 26 頁）三種切塊都不在前 8；X1 跨文件題前 5 只來自一份文件（Document-aware Retrieval 是選做，§9.6）；G4 在 600 時條件段落掉出前 5。
- **沒做的**：回答正確性的新實驗。檢索指標最好的組合就是目前的預設（400×5、Vector），它的回答正確性已有 C／A／B 到 B7 共 100 多次真實模型紀錄（`../navigator-abc/`）；Hybrid 未達採用條件，不另跑 LLM。10K 合規率與延遲見各批紀錄的帳本斷言（每次呼叫 ≤ 10,000，實驗工具斷言）。
