# navigator-abc — 單輪 vs. 同 prompt 雙角色 vs. 導航取證的 A/B/C 實驗（D71）

問題：D69 的條件修正只對檢查看得到的錯有效；D70 顯示模型能初步定位「要看哪一節、哪個表」。使用者提出假設：先讓模型當 **Navigator** 指出證據位置、再當 **Analyst** 依證據分析，可能比單輪更完整、更正確；並要求分離兩個變因——**角色分工本身**（A 對 C）與**中途重新取證**（B 對 A）。ADR 0009。

## 設計

| 臂 | 設定 | 呼叫 | 證據 | 說明 |
|---|---|---|---|---|
| C 單輪 | `ANSWER_MODE=single` | 1 | Top-5＋表格擴充（摘要路線：預存摘要） | 現行預設 |
| A 同 prompt 雙角色 | `ANSWER_MODE=roles` | 1 | **與 C 完全相同** | prompt 前段加文件地圖與兩角色指示：先以 Navigator 列出該看的章節／表／頁（不得寫事實），再以 Analyst 作答 |
| B 導航取證 | `ANSWER_MODE=navigate` | 2 | C 的證據全留，計畫取回的切塊附在後面、在預算內依序納入 | 第一次呼叫（`purpose=navigate`）看地圖與來源標頭寫閱讀計畫；程式對地圖定位、取該頁／該表的切塊；第二次呼叫作答，計畫標為「候選、未驗證」 |

- **同批、同文件、同設定、同期**：三臂在同一次 `pytest` 中跑完（2026-11-06，45 次執行，端到端合計 887 秒）。兩篇論文各上傳一次、各跑一次摘要工作（地圖要章節標題與頁碼範圍）；模型 qwen3:32b、Top-K 5、切塊 400／80、門檻不變。
- **問題**：Q1 全文摘要、Q2 LightRAG vs GraphRAG、Q3 消融實驗（LightRAG 論文）；G1 context units 與 tokens、G2 C2 對 SS 的 comprehensiveness（Graph RAG 論文，arXiv:2404.16130v2）。每臂每題 3 次。D72 的路由修正先提交，三臂共用，G1 不再被送去摘要路線。
- **真值**：`../ground-truth/evidence-locations.{md,json}`（必要內容所在的章節／表／頁與原文片段）、`key-facts.md`、`graphrag-key-facts.md`。只用於評測，不進任何 prompt；程式裡沒有論文字面、表名或數字。
- **紀錄**：每次執行一個 `runs/<臂>-<題>-<次>.json`：設定、階段、來源全文（供 Coverage 離線計算）、閱讀計畫與逐塊取捨紀錄、最終回答、`done`、每筆 LLM 呼叫的 tokens 與時間。`analyse.py` 產生 `analysis.json`（逐次指標）與 `answers.md`（45 份回答全文＋計畫＋檢查結果）。
- **執行**：`pytest -m llm tests/integration/test_navigator_abc_real.py -s`（`ABC_ARMS`、`ABC_QUESTIONS`、`ABC_RUNS` 可縮小範圍）；`.venv/bin/python evaluation/navigator-abc/analyse.py`。

## 要誠實說的

- **三次是初步探索**，不宣稱統計顯著；A 比 C 多 2 次通過全在 Q2，差距在三次內可被一次隨機波動抵銷。
- **Q1 的失敗是入庫時的章節摘要寫錯**，三臂共用同一份摘要，與回答模式無關；D69 那批的摘要沒有這句、Q1 三臂 3/3。Q1 的品質取決於摘要工作那一次生成，回答端的核對能抓到但不能修。
- **人工判定由 AI 做**，逐格對過 `paper-structure.json` 的 Table 1／Table 2 與 `graphrag-key-facts.md`；使用者抽查待補。三次「無錯誤但必要內容不足」（A-Q3-2、B-Q3-2、B-G2-2）若使用者認為應算通過，A 為 8/15、B 7/15、C 5/15。
- **B 的多餘證據比例 86%**（73/85）：地圖只到章節層級，一節 6 頁就取前 8 塊；預算先到先得，後面的計畫項（往往是真正需要的附錄表）被排除；沒有依問題相關度篩選。這是機制設計的問題，不是模型的問題（計畫 85 條全部定位到）。
- **B 的事實性錯誤比 C 多**（6 次對 2 次）：拿到表格切塊後模型寫更多數字（B-Q2-3 32 個、B-Q3-3 25 個），對的多、錯的也多；對 Demo 而言「多寫一個錯的數字」比「少寫一個對的數字」更傷。
- 延遲與 token：A 幾乎免費（＋8%／＋16%）；B 每題多等約 15 秒、tokens 2.1×，且第一次呼叫期間使用者只看到「navigating」階段，沒有串流文字。

## 結論（供使用者決定）
