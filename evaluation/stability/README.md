### 讀法

- 溫度 0 的三題合計 29/30，泛化 20/20；溫度 0.4 的三題合計 22/30，泛化 20/20。
- 0.4 的錯誤集中在 Q3：變體定義望文生義（-High 被讀成「只有 high-level」，論文的意思是「拿掉 high-level」）與例外的資料集標籤。這兩類都不是數字錯——數字來自事實塊，十次全對——而是模型對名稱的詮釋與排版時的歸類。表格數字的標籤錯有頁尾核對會標出；定義反向目前沒有機制抓（事實塊只有數字，不帶定義）。
- 溫度 0 不是零風險：Q3 十次中仍有 1 次定義反向（這一篇的開頭與其他九篇不同，應是 Ollama 在 temperature 0 下仍有少量非決定性）。
- GraphRAG 論文的四題兩種溫度都全過，說明數字類與定義類（G4 六個條件）的題目在另一篇論文上也穩定；三題中最難的是 Q3 這種「多格歸納加名稱詮釋」。
