# AGENTS.md

This project keeps a single source of truth for AI coding agents.

**Read [`CLAUDE.md`](CLAUDE.md) and follow it.** It defines the hard constraints
from the assignment (text-only LLM, 10K-token context limit, no fabricated
answers), the commands, the architecture boundaries, the SDD → TDD → Checkpoint
workflow, and how interactions with the user must be recorded.

The file is written in Traditional Chinese; the rules apply to every agent
(Claude Code, OpenCode, Codex, …) regardless of the tool's own conventions.
