## P2-A 帳號與骨架

### 目標

能註冊與登入；確認 Ollama、Embedding、pgvector 能串起來。

### 做了什麼

- **資料表**：`users`、`sessions`、`documents`、`ingestion_jobs`、`chunks`、`conversations`、`messages`、`llm_calls`。Migration `0002` 由 Alembic 產生明確的建表指令；狀態欄位有資料庫層的檢查限制。
- **帳號 API**：`POST /auth/register`、`POST /auth/login`、`POST /auth/logout`、`GET /users/me`。分 router、service、repository 三層。
- **密碼**：Argon2id，`argon2-cffi==25.1.0`（`../03-decisions/0004-session-auth-argon2id.md`）。
- **Session**：隨機 token，資料庫只存 SHA-256；Cookie 為 HttpOnly、SameSite=Lax；每次登入發新的並刪除請求帶來的舊 Session。
- **來源檢查**：有 `Origin` 看 `Origin`，沒有則看 `Referer`，兩者皆無或不在清單回 `403`；掛在所有 API 之前、驗證登入之前。
- **API 前綴**改為 `/api/v1`，健康檢查為 `GET /api/v1/health`，API 文件在 `/api/v1/docs`。統一的錯誤格式 `{detail, code}`。
- **環境變數**：`DB_*`、`HTTP_OLLAMA_*`，只由 `app/core/env_loader.py` 讀取；範例檔改名 `.env.sample`。
- **前端**：登入、註冊、登入後首頁（名稱、系統狀態、登出）。
- **最小流程驗證腳本** `scripts/smoke_rag.py`（`make smoke`）。
- **其他**：`.gitignore` 補規則；`sample-documents/README.md` 標明論文的來源與授權（CC BY-NC-SA 4.0）；`CLAUDE.md` 移除公司名稱並更新專案說明。

### 困難與解法

| 現象 | 根因 | 嘗試過 | 解法 | 學到 |
|---|---|---|---|---|
| 測試列舉不到任何 API 路由 | 這版 FastAPI 把掛入的路由包成一個物件，不再攤平成個別路由 | 直接列舉 `app.routes` | 改由 OpenAPI 文件列出所有路徑與方法 | 驗收用的檢查盡量依賴公開的契約，不依賴框架內部結構 |
| Session Fixation 的測試讀 Cookie 失敗 | 測試手動放入的 Cookie 與伺服器設定的同名 Cookie 並存 | — | 改從登入回應的 `Set-Cookie` 取新值 | 測試工具的 Cookie 罐行為與瀏覽器不同，斷言要針對回應本身 |
| 第一版 migration 直接由模型建表 | 日後改模型會改變舊 migration 的結果 | — | 改用 Alembic 自動產生明確的建表指令，並驗證降版再升版 | migration 必須是固定的歷史，不能跟著模型變 |
| pre-commit 對腳本報了三個問題 | 有 shebang 但不可執行、多餘的忽略註解、未加括號的多行字串 | — | 逐一修正 | 新檔案在提交前就跑 pre-commit，不要等到最後 |
| AI 把「本地領先遠端 3 個提交」說成「遠端多 3 個提交」 | 讀反了指令輸出的左右欄 | — | 以兩個獨立的指令重新查證後更正 | 涉及遠端狀態的判斷要用不會讀反的方式確認 |
