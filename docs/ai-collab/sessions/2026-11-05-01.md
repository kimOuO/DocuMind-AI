## 遇到的問題

| 現象 | 根因 | 解法 |
|---|---|---|
| `python3 -m venv` 無法建立含 pip 的環境 | 系統 Python 沒裝 `python3.12-venv`（缺 `ensurepip`） | 用 `--without-pip` 建環境，再以 `get-pip.py` 補 pip，不需 sudo；`make setup` 內建這個後備流程 |
| 後端測試收集失敗：缺 `greenlet` | SQLAlchemy 非同步引擎需要 `asyncio` extra | `requirements.txt` 改為 `SQLAlchemy[asyncio]` |
| Vite 樣板用 oxlint 而非計畫中的 eslint | 上游樣板已更換預設工具 | AI 先沿用 oxlint 且未先詢問；使用者要求改回 eslint（D19） |
| eslint 與 TypeScript 7.0 不相容 | typescript-eslint 只支援 `<6.1.0` | TypeScript 降到 6.0.3（D21） |
