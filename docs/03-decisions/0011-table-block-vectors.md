# ADR 0011：多區塊表格以區塊向量計分（一區塊一向量，取最佳）

- 狀態：已採用（2026-11-07）
- 日期：2026-11-07
- 對應決策日誌：D81（三個檢索洞的原因）、D82（使用者提出的解法與實驗工具量測）、D83（納入正式程式後的 C8／B8 測試）
- 數據：`evaluation/retrieval-parameters/`（多向量欄）、`evaluation/navigator-abc/`（C8、B8）

## 背景

P4 的題庫量測發現，純向量檢索對「比較 LightRAG 與 GraphRAG」拿不到 Table 1：那一塊 chunk 排第 14 名（相似度 0.582），前五是四段談論比較的散文。拆開量測同一張表的不同部分與問題的相似度：

| 文字 | 相似度 |
|---|---|
| 4.2 節的段落（第 1 名） | 0.622 |
| Table 1 整塊（四組 baseline、128 個數字） | 0.582 |
| Table 1 只留標題與表頭 | 0.576 |
| Table 1 只留被問的那一區塊（GraphRAG 對 LightRAG 的四列） | 0.669 |

一塊裝了四組比較，向量是四件事的平均；問題只問其中一件，就被稀釋。問題不在表裡有沒有出現名字（GraphRAG 出現 20 次），在一塊裡有幾件事。

## 考慮過的選項

| 選項 | 做法 | 結果／取捨 |
|---|---|---|
| 1. Hybrid（向量＋全文檢索，RRF） | 關鍵字計數不受稀釋 | 能把 Table 1 拉進前五，但整體 Recall 0.74 低於 Vector 0.88，在三題把導論頁擠進來；未達採用條件（ADR 0010） |
| 2. 問題的詞對表格表頭的程式規則 | 問題裡的詞出現在某張表的表頭就補那張表 | 通用、便宜，但等於用程式重做 Navigator 的一部分，且只對表頭有名字的情況有效（AI 提議，使用者質疑後擱置） |
| 3. 入庫時把多區塊表格切成一區塊一塊 | 每塊自成 chunk | 區塊向量乾淨，但消融題（Q3）要四個區塊一起看，整張表一塊一次拿到是它目前穩定的原因；矩陣與核對程式也假設一張表的配對在同一來源 |
| **4. 一區塊一向量、chunk 取最佳（採用）** | chunk 不切，另存每個區塊的向量；chunk 的距離取自身與各區塊向量的最小值 | 使用者提出。Q3 的整塊不變，Q2 透過 GraphRAG 區塊的向量找到整塊；只對多區塊表格生效，散文不變；不比對任何名稱 |

## 決定

採用選項 4：

- 入庫（`app/ingestion/tables.py::table_blocks`、`chunking.py`、`indexing.py`、`repository.py`）：多區塊表格的 chunk 依區塊表頭切段，第一段帶標題行與完整表頭，其餘各段帶標題行、群組表頭與自己的區塊表頭；每段各算一個 `bge-m3` 向量，存入 `chunk_vectors`（migration 0006，外鍵隨 chunk 刪除）。區塊靠表格自己重複出現的表頭行辨認。
- 檢索（`app/retrieval/repository.py::search`）：chunk 自身向量與其區塊向量 UNION 後依 chunk 取最小距離，排序取前 K；回傳仍是整塊 chunk 與它的文字。
- 先在實驗工具內用已存 chunk 量測（7d9586a），確認後才改正式程式（6fa083a）。

## 數據

實驗工具（切塊 400，K＝5）：Q2 的 Table 1 由第 14 名（0.582）到第 1 名（0.650）；Q2 的前五由「4.2 段＋4.5 增量更新段」變成「Table 1＋4.2 段」，Recall 同 0.50；K＝8 時 0.93 對 0.91；表格題 top-1 普遍上升，Q3、T2、T3、G1、G2 不變或更高；整體 400×5 Recall 0.88、命中率 1.00 不變。第一版把第一區塊的欄表頭帶給所有區塊，GraphRAG 區塊只到 0.638；每區塊只帶自己的表頭後 0.650。

真實模型（C8／B8，三個必答題各 3 次，含此變更）：見決策日誌 D83 與 `evaluation/navigator-abc/README.md`（待補）。

## 後果

- 入庫多一批嵌入呼叫（兩篇論文各 8、16 段），時間幾乎不變；資料庫多一張表。
- 已入庫的文件沒有區塊向量，要重新上傳才會生效；Demo 前正式資料庫要重建。
- 前五名額不變，一張表進來就有一段散文被擠出去——這是 Top-K 的性質，不是這個改動能解的。
- 區塊的切法依賴表格偵測與逐列改寫（ADR 0007、D81）；像 GraphRAG Table 6 那種表頭形狀無法逐格改寫的表，區塊切法以指標名稱的區塊表頭為界，仍可用。
